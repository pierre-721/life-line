# Simulation de vie — réservée aux prochaines phases

Aucune logique de simulation pour la phase 1. Les valeurs du HUD sont des données de démonstration statiques.

Les futurs modèles (temps, activités, besoins, relations, sauvegarde) devront rester indépendants de Phaser, du DOM et du rendu. Le jeu consommera leurs états et leur transmettra les actions du joueur. Ne pas ajouter d'abstractions avant leur premier usage réel.
